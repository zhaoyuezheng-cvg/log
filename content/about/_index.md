# 关于这里

欢迎来到我的个人博客。

最初搭建这个博客，只是图个简单省事，追求纯粹的高效。我放弃了臃肿的 WordPress，选择了 Hugo，并把它部署在 GitHub 和 Cloudflare 上，希望自己能专注于内容本身。

但作为一个程序员，我显然没能逃过“造轮子”的宿命。为了让更新不那么繁琐，我花了一整天的时间，用 AI 帮我手搓了一套自动化排版、校对和生成封面的工具链。看着这个完美运行的系统，我突然陷入了沉思：我到底是在写博客，还是在折腾博客？

不过，折腾归折腾，工具终究只是工具。

这里会记录我的技术探索、生活随笔，以及一些无用的奇思妙想。希望在这个纯粹由静态页面构成的角落里，能和你分享一些有价值的思考。

好好写东西，少折腾代码。共勉！
