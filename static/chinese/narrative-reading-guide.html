一
必考题型一：概括文章主要内容与梳理情节
2个问法
问法 1
简要概括文章的主要内容或文中多个主要事件
📌 答题公式：概括内容 = 时间 + 地点 + 人物 + 起因 + 经过 + 结果
1
审清题目：找到题干中的关键词（如：概括、内容、事件），确定该题考查题型为概括主要内容或事件
2
找准要素：找人物，明确每个人分别做的事件；确定要概括的人物及对应事件；找到"时间、地点、人物、起因、经过、结果"的关键信息（六要素不需要面面俱到，文中没有明确或没有必要概括的要素，可省略）
3
组织语言：根据具体内容，套用模板作答
公式作答
概括内容 = 时间 + 地点 + 人物 + 起因 + 经过 + 结果
答题模板：人物（在……时间/地点），因为……，做了……事情，结果是……。
问法 2
梳理文章的情节
📌 答题公式：梳理情节 = 确定区间 + 结合信息 + 找关键词（时间/地点/人物/事件）
1
审清题目：找到题干中的关键词（如：梳理、内容、事件、情节），确定该题考查题型为梳理情节
2
提取信息：通读全文，全面把握文章内容；结合表格所给信息或题干提示，确定答题区间；抓住文中的关键词句进行提炼。
口诀：定信词（定心词）
3
组织语言：根据表格或题干中的提示，总结语句结构，进行填写
公式作答
梳理情节 = 确定区间 + 结合信息 + 找关键词（时间/地点/人物/事件）
答题模板：在时间/地点，……（人物）……（事件）。（各要素可根据具体情况选用）
二
必考题型二：分析人物情感与形象
2个问法
问法 3
分析人物的情感 / 心理
📌 答题公式：分析情感/心理 = 情节/关键词 + 选择角度 + 人物情感/心理
1
审清题目：找到题干中的关键词（如：情感、揣摩、心理），确定该题考查题型为分析人物情感/心理
2
找准角度：
  • 人物描写角度：抓住语言、动作、神态、心理的句子
  • 环境描写角度：抓住描写的环境特点和氛围
  • 关键词角度：抓住动词和形容词等，结合词语特点和含义分析
  • 修饰限制词语角度：抓住修饰、限制性词语，分析人物的心理变化过程
  • 修辞手法角度：抓住运用比喻、拟人修辞手法的句子
  • 文章主题角度：结合文章主旨，准确把握人物的情感/心理
3
组织语言：结合文章具体内容，选取角度进行分析，套用模板
问法 4
分析人物形象特点
📌 答题公式：人物形象 = 描写手法 + 具体内容（相关事例/他人评价）+ 形象特征
1
审清题目：找到题干中的关键词（如：人物、特点、形象、怎样的人），确定该题考查题型为分析人物形象特点
2
找准角度：
  • 人物职业/身份/地位/经历
  • 描写手法（正面描写/细节描写/环境描写/侧面描写）
  • 主要事件，结合人物的角色/做事的动机/处事的方式
  • 能直接体现人物性格特点的词语
  • 文中议论/抒情的句子，体会作者对人物的情感/态度/评价
3
组织语言：结合文章具体内容进行分析，套用模板作答
三
必考题型三：标题的含义及作用
2个问法
问法 5
理解文章标题的含义
📌 答题公式：标题含义 = 表层含义 + 深层含义 + 情感/主旨
1
审清题目：找到题干中的关键词（如：标题、含义、内涵），确定该题考查题型为标题含义
2
明确方法：
  • 表层含义：从标题本身看，理解字面含义
  • 深层含义：结合文章内容，联系中心，进一步理解深层含义
  • 情感主旨：分析标题所表达的情感主旨
口诀：表深情
3
组织语言：结合文章内容，套用模板作答
公式作答
标题 = 表层含义 + 深层含义 + 情感/主旨
答题模板：表层含义是……（内容）；深层含义是……（内容），表达了……的情感/主旨。
问法 6
分析文章标题的作用
📌 答题公式：标题作用 = 结合文章内容 + 匹配作用（内容/结构/其他）
1
审清题目：找到题干中的关键词（如：标题、作用），确定该题考查题型为标题作用
2
找准角度：
  • 内容：交代写作对象；概括文章内容；点明主旨；暗含主旨
  • 结构作用：行文线索，贯穿全文，推动情节发展
  • 其他：设置悬念，激发读者阅读兴趣；以诗词开篇，则呈现美好的意境，增加文采；富有诗意
3
组织语言：根据文章具体内容，选取角度进行分析，套用模板
公式作答
标题作用 = 结合文章内容 + 匹配作用（内容/结构/其他）

必考题型四：把握文章主旨
1个问法
问法 7
理解并分析文章主旨
📌 答题公式：文章主旨 = 分析内容 + 表达情感/揭示道理
1
审清题目：找到题干中关键词（如：主旨理解），确定该题考查分析文章主旨
2
找准角度：
  • 从文章标题入手
  • 从文章的开头或者结尾入手
  • 从议论或者抒情的语句入手
  • 从文章写作背景入手
  • 从中心人物与核心事件以及作者的感情倾向入手
口诀：标头尾 写抒心
3
组织语言：根据文章具体内容，选准角度进行分析，套用模板
公式作答
文章主旨 = 分析内容 + 表达情感/揭示道理
答题模板：通过……故事/描写，歌颂（赞美）了……（景物特点/人物形象）/ 表达了作者……的思想感情 / 揭示了……的深刻道理。

必考题型五：赏析句子的表达效果
4个问法
问法 8
从加点词语的角度赏析句子
📌 答题公式：词语赏析 = 词语含义 + 描述内容 + 表达效果/情感
1
审清题目：找到题干中的关键词（如：加点词、表达效果），确定该题考查题型为词语赏析
2
找准角度：
  • 修辞手法：找出比喻、拟人、夸张、排比等，分析表达效果
  • 方言口语：突出地域特色，传达乡土情韵，具有民族特色
  • 词性及效果：分析动词、形容词、拟声词、数词、叠词、副词等词语的表达效果
  • 词类活用：通过词语活用，丰富语言的表现力
  • 感情色彩及变化：褒词贬用、贬词褒用
3
组织语言：根据句子内容，选准角度进行分析，套用模板
问法 9
从描写方法的角度赏析句子
📌 答题公式：描写赏析 = 辨析描写方法 + 分析内容 + 作用效果 + 主旨情感
1
审清题目：找到题干中的关键词（如：赏析、语句、描写、作用），确定该题考查题型为从描写角度赏析句子
2
找准角度：
  • 人物描写：语言、动作、心理、神态、外貌 → 表现人物性格/特点/形象
  • 环境描写：自然环境、社会环境 → 交代背景；渲染气氛；推动情节；烘托心情；深化主题
口诀：辨析用情
3
组织语言：根据具体文章内容，选准角度进行分析，套用模板
公式作答
描写赏析 = 辨析描写方法 + 分析内容 + 作用效果 + 主旨情感
答题模板：运用……描写，生动形象地写出了……，描写/奠定了……，表现了/深化……的情感/主题。
问法 10
从修辞手法的角度赏析句子
📌 答题公式：修辞赏析 = 辨析修辞 + 分析内容 + 作用效果 + 主旨情感
1
审清题目：找到题干中的关键词（如：赏析、语句、修辞、表达效果），确定该题考查题型为从修辞角度赏析句子
2
找准角度：
  • 比喻：把……比作……，生动形象写出了……
  • 拟人：把……赋予人的……，生动形象写出了……
  • 排比：强调了……的特点，句式整齐匀称，语势强劲
  • 夸张：突出了……的特征，强调了……的思想感情
  • 反复：加强了语气，强烈表达了……之情
  • 反问/设问/对偶/通感：详见各修辞手法答题模板
3
组织语言：根据句子运用的修辞手法，套用相应的模板作答
问法 11
从表现手法的角度赏析句子
📌 答题公式：表现手法赏析 = 辨析手法 + 分析内容 + 作用效果 + 主旨情感
1
审清题目：找到题干中的关键词（如：赏析、语句、修辞、表现手法），确定该题考查题型为从表现手法赏析句子
2
找准角度：
  • 对比：将……和……进行对比，突出表现了……，表达了……情感
  • 照应：使文章结构严谨，情节完整，中心突出
  • 象征：使被象征的内容得到含蓄而形象的表现，借眼前之物寄托深远之意
  • 渲染烘托：层层铺叙，营造意境，使描写的形象更加鲜明突出
  • 欲扬先抑：形成对比，突出……，使情节更曲折，引人入胜，形象更丰满
3
组织语言：根据句子运用的表现手法，套用相应的模板作答

2

  • 第二人称：增加亲切感，拉近与读者的距离；便于直接对话和抒情，有呼告效果；用于物，有拟人化效果
  • 第三人称：直接、客观地展现生活，不受时空限制，能从多方面自由叙述，写作较自由灵活
3
