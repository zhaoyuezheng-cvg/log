答案1．A

选 A。

A 全对　菜畦（qí）✓　确凿（záo）✓　绿草茵茵（yīn）✓

B 错　"着落"读 zhuó luò（不读 zháo）。着落：依靠、指望。

C 错　"脊梁"读 jǐ liáng（不读 jí）。脊：脊背。

D 错　"迷惘"读 mí wǎng（不读 mǎng）。惘：失意、困惑。

速记　着（zhuó）落 ≠ 着（zháo）急；脊（jǐ）梁 ≠ 脊（jí）背（"脊"统读 jǐ）；迷惘（wǎng）≠ 迷茫（máng）。

答案2．D

选 D。

A 错　"应合"应为 "应和"（yìng hè，呼应、附和）。"合"与"和"混淆。

B 错　"奥密"应为 "奥秘"（深奥神秘）。"密"与"秘"混淆。

C 错　"感概"应为 "感慨"（有所感触而慨叹）。"概"与"慨"混淆。

D 全对　鉴赏、草垛、质朴、混为一谈，书写均正确。

易混字辨析　应和（和：呼应）≠ 应合；奥秘（秘：神秘）≠ 奥密；感慨（慨：慨叹）≠ 感概；混为一谈（混：混同）≠ 浑为一谈。

答案3．B

选 B。

B 有误　"不可抗拒"指无法抵抗的力量（如自然灾害、历史潮流），不能用来形容掌声。应改为"情不自禁"（抑制不住自己的感情）。

A 恰当　"喜出望外"：遇到出乎意料的喜事而特别高兴。生日收到笔记本电脑确实是意外惊喜，使用正确。

C 恰当　"各尽其能"：各自发挥自己的才能。运动员比赛、文学高手写稿、啦啦队活跃，各有分工，使用正确。

D 恰当　"形影不离"：像身体和影子一样分不开，形容关系亲密。用来形容好朋友，使用正确。

答案4．A

选 A。

①→娇嫩、柔弱，让人怜惜　"春天的花儿是草本的"——草本花娇嫩柔弱，与"怜惜"搭配。

②→灿烂、刚毅，让人赞叹　"秋天的花儿就是木本的"——木本花/叶灿烂刚毅（如红叶），与"赞叹"搭配。

③→叶子燃烧成花朵，花朵沉淀成醇酒　秋光照耀叶子上，叶子变红如花（燃烧），花落酿成秋意如酒（沉淀）。先"燃烧"后"沉淀"，与"铺天盖地"的视觉冲击衔接。

排除　BC ②颠倒（春≠灿烂刚毅）；CD ③颠倒（应先"燃烧"后"沉淀"）。

【甲】陈太丘与友期行，期日中。过中不至，太丘舍去，去后乃至。元方时年七岁，门外戏。客问元方："尊君在不？"答曰："待君久不至，已去。"友人便怒曰："非人哉！与人期行，相委而去。"元方曰："君与家君期日中。日中不至，则是无信；对子骂父，则是无礼。"友人惭，下车引之。元方入门不顾。

（《陈太丘与友期行》）

【乙】宾客诣陈太丘宿，太丘使元方、季方炊。客与太丘论议，二人进火①，俱委而窃听，炊忘著箅②，饭落釜中。太丘问："炊何不馏③？"元方、季方长跪曰："大人与客语，乃俱窃听，炊忘著箅，饭今成糜④。"太丘曰："尔颇有所识不？"对曰："仿佛志⑤之。"二子俱说更相易夺⑥言无遗失。太丘曰："如此，但糜自可，何必饭也！"

（《世说新语》）

【注释】①进火：烧火。②著：放。箅（bì）：蒸锅中的竹屉。"箅"的作用是使米不漏到锅中。③馏（liù）：把米放在水里煮至水开，再捞出蒸成熟饭。④糜（mí）：比较稠的粥。⑤志：记忆。⑥更相：互相。⑦易夺：改换、补充。

答案5．词语解释

①舍弃（丢下）　②锅　③c（略微，稍微）　④改换、补充（互相纠正补充）

①委　课内"相委而去"（《陈太丘与友期行》）= 舍弃、丢下。"俱委而窃听"= 都丢下（做饭的事）去偷听。

②釜　成语"破釜沉舟""釜底抽薪"中"釜"= 锅。"饭落釜中"= 饭掉到锅里。

③颇　选 c.略微，稍微。"尔颇有所识不？"= 你们还记得一些吗？孩子们回答"仿佛志之"（隐约记得），说明父亲问的是"是否稍微记得"，而非"是否记得很多"。

④易夺　本义"改变、夺取"，此处结合语境"二子俱说更相易夺言无遗失"= 两个孩子互相改换补充，说的没有一点遗漏。两人互相纠正、补充对方的说法，合在一起就完整了。

答案6．导演手记

①陈太丘（欣慰（温和、宽容））地说："（你们还记得一些吗？/ 你们有所领悟吗？）"

推理依据　乙文写孩子们因偷听讲学而忘了做饭，太丘问"尔颇有所识不"（还记得些吗），孩子答"仿佛志之"，太丘随即说"但糜自可，何必饭也"（喝粥就行，不必吃饭）。可见太丘不生气反而欣慰，因为孩子们偷听学到了东西。语气应温和、鼓励，而非责备。

答案7．断句

二子俱说 / 更相易夺 / 言无遗失。

翻译验证　"两个孩子一起说，互相改换补充，说的没有一点遗漏。"三组动作：①俱说（一起说）→ ②更相易夺（互相补充纠正）→ ③言无遗失（说的没遗漏）。在"俱说"和"易夺"后各断一处。

答案8．方正 + 夙慧

方正（正直、合乎道义）：甲文中，友人怒骂元方父亲"非人哉"，年仅七岁的元方面对成人的无礼指责，毫不畏惧，以"日中不至则是无信，对子骂父则是无礼"当面驳斥，指出友人既无信又无礼，维护了父亲的尊严，行为正直、合乎道义。

夙慧（早慧、聪慧过人）：乙文中，元方和季方偷听父亲与客人论议，虽忘了做饭，但能"仿佛志之"（隐约记住），且"二子俱说更相易夺，言无遗失"——两人互相补充纠正，说的没有一点遗漏。小小年纪能过耳不忘、互相补正，展现幼童聪慧过人。

答题公式　方正 → 引甲文具体言行（驳斥友人"无信""无礼"）→ 分析正直合道义。夙慧 → 引乙文具体表现（窃听、仿佛志之、更相易夺无遗失）→ 分析聪慧过人。两方面都要答到。

答案9．诗歌阅读

（1）本诗在先，《闻王昌龄左迁龙标遥有此寄》在后。

本诗写王昌龄在龙标贬所的生活场景——夏晚凉风中携酒就竹丛，弹弦唱歌，"莫道弦歌愁远谪，青山明月不曾空"表现他随遇而安、不以远谪为愁的旷达态度。这是被贬之后在贬所的生活。而李白的诗"我寄愁心与明月，随君直到夜郎西"写的是听闻友人被贬后的担忧与牵挂，"闻道龙标过五溪"表明李白是得知贬谪消息后所作。因此本诗先于李诗。

（2）两首诗"明月"作用不同：

本诗："青山明月不曾空"——明月与青山相伴，象征自然美景永远不空缺、不亏待任何人。即使遭远谪，明月依然高悬。表达诗人随遇而安、旷达乐观的心境：贬谪虽苦，但青山明月足以慰藉，不以远谪为愁。

李白诗："我寄愁心与明月，随君直到夜郎西"——明月是情感使者，诗人把愁心托付给明月，让明月一路陪伴友人到贬谪之地。表达对友人的思念、同情与牵挂，以奇特想象将关怀推向极致。

对比　同一"明月"意象，王昌龄笔下是旷达自适的见证（明月不空，心也不空）；李白笔下是深情寄托的载体（明月传愁心到夜郎）。一豁达一深情，各有千秋。

答案10．古诗文默写

（1）枯藤老树昏鸦，小桥流水人家。

（2）子曰：饭疏食，饮水，曲肱而枕之，乐亦在其中矣。

（3）不必说碧绿的菜畦，光滑的石井栏，高大的皂荚树，紫红的桑椹；也不必说……

（4）《夜上受降城闻笛》中写出了受降城亘古苍茫的句子是：回乐烽前沙似雪，受降城外月如霜。

易错字　藤（不是"滕"）；曲肱（肱 gōng，胳膊；不是"弓"）；皂荚（不是"皂夹"）；桑椹（不是"桑葚"——课文原文用"椹"）；烽（不是"锋"）。

第（4）题理解　"亘古苍茫"指从古至今的苍凉辽远。"沙似雪"写沙漠如雪般白茫茫，"月如霜"写月光如霜般冷冽——沙与月交融，营造出受降城外亘古苍茫的边塞景象。

【甲】陈太丘与友期行

原文译文
陈太丘与友期行，期日中。
陈太丘和朋友相约同行，约定的时间是正午时分。
过中不至，太丘舍去，去后乃至。
过了正午朋友还没有到，陈太丘丢下（他）而离开。太丘离开后朋友才到。
元方时年七岁，门外戏。
元方当时年龄七岁，在门外玩耍。
客问元方："尊君在不？"
客人问元方："令尊在不在？"
答曰："待君久不至，已去。"
（元方）回答说："（我父亲）等您很久您没来，已经离开了。"
友人便怒曰："非人哉！与人期行，相委而去。"
友人便生气地说："真不是人啊！和别人相约同行，却丢下别人先离开了。"
元方曰："君与家君期日中。日中不至，则是无信；对子骂父，则是无礼。"
元方说："您与我父亲约定的时间是正午。正午您没到，就是不讲信用；当着儿子的面骂他的父亲，就是没有礼貌。"
友人惭，下车引之。元方入门不顾。
友人感到惭愧，下车去拉元方的手。元方头也不回地走进了家门。

【乙】宾客诣陈太丘宿

原文译文
宾客诣陈太丘宿，太丘使元方、季方炊。
有客人到陈太丘家过夜，太丘让元方、季方兄弟去做饭。
客与太丘论议，二人进火，俱委而窃听，
客人与太丘谈论（学问），兄弟俩在烧火，都丢下（做饭的事）去偷听，
炊忘著箅，饭落釜中。
做饭忘了放蒸屉，饭都掉到了锅里。

现代文阅读（一）《石榴花开》

12 分 · 纪明涛 · 考点：引用作用 / 语言赏析 / 结尾比较

①行走在初夏的早上，尽是雨后的微凉和氤氲的绿意，令人神清气爽。清晨，在小区健身廊道跑步锻炼时，忽然瞥见路边花园里有几株石榴树开花了。"只待绿荫芳树合，蕊珠如火一时开。"远看，石榴树上开满许多小喇叭似的花朵，红红的，缀满在朦胧的绿丛里，灿若烟霞。

②我不由得停下脚步，走近栅栏，来到石榴树下，仔细端详。昨夜下了一阵小雨，空气是那样清新，石榴树的枝叶上还有一层水滴。绿叶红花，点缀滴滴晶莹露水，石榴花越发显得纤细、秀美、娇艳。

③古人把石榴称作"丹若"，就是取自石榴花的颜色。据《广群芳谱》记载："石榴，一名丹若，本草云：若木乃扶桑之名，榴花丹颇似之，故有丹若之称……"说起来石榴算是外来物种，汉朝时传入我国。先是在皇家苑囿中栽种，后来随着时代变迁，才飞入寻常百姓家。

④红红的石榴花，一树树，一簇簇，一团团，抓人眼球，张力十足，灼热、烂漫、飞扬，充满了蓬勃的生命感，成为初夏时节一道绚丽的风景线。望着石榴花，遐想着金秋时满树的石榴果，我的思绪又飘飞到老家的那棵石榴树身上。记不清楚是哪一年，母亲在院子里栽下了一棵石榴树。刚栽种的时候，它只有大拇指般粗细，起初我没怎么关注过它。直到几年后，石榴树枝繁叶茂，石榴花怒放，秋后果实累累，让儿时的我有了大快朵颐的美味。在零食匮乏的年代，那棵石榴树结出的果实，汁液饱满，甜而不酸，还未入口，已让我满口生津，成为我童年味蕾的一份留恋。

⑤石榴树很容易培植，母亲每年都通过压条植根的方法培育幼苗，对有需要的左邻右舍，母亲总是把幼苗慷慨相赠。石榴树的成长少不了母亲的精心呵护，经过几十年的生长，石榴树的躯干已有碗口那么粗，斑斑驳驳，疙疙瘩瘩，仿佛写满了岁月的沧桑。每次看到那棵石榴树，我的眼前总会浮现出母亲劳作的身影。母亲用一双布满老茧的手，操持着农活和家务，日复一日地为家庭付出，从无怨言。石榴树的品格，不正像我的母亲吗？没有奢华的外表，却勤勤恳恳，甘于奉献。

⑥农历五月，是石榴花盛开的时节，故五月又称"榴月"。盛开的石榴花将静谧的小庭院映衬得热闹缤纷。石榴花的花期比较长，但若是遇到较大的风吹拂，花瓣便纷纷落下，在地上像是铺上了一层红色的地毯，踩上去软绵绵的，有一种说不出的舒爽萦绕在心头。

⑦等到了盛夏，如伞一般的树冠下，更是成了乘凉休憩的好地方。晚饭后，母亲在树下做一些诸如纳新鞋底之类的针线活，有时也会给我讲岳飞、海瑞的故事，教一些做人的道理。到10月份，是石榴的收获季节，细心的母亲总是按成熟的先后顺序采摘。母亲把采摘下来的石榴保存得特别仔细，先是将石榴放在阴凉通风的地方，待石榴皮的水分蒸发后，母亲把果皮干燥好的石榴放到一种略显青色的、柔软的草纸上，一包一折，一滚一顿，尽量排出空气，让每一层纸都包裹严紧，最后把纸的一角掖进纸层中，便大功告成了。直等到春节期间拿出来招待客人。

⑧"却是石榴知立夏，年年此日一花开。"此刻，眼前的石榴花活泼、灵动，像一簇簇跳动的火苗，又像一片红艳艳的晚霞，充满生机，热烈热闹。老屋、古巷、石板路、石榴花，在今天的都市里似乎很难找到了，而眼前的这几株石榴树，浓缩了故乡的远景，浓缩了我儿时的记忆和快乐，也浓缩了我对故乡依依不舍的思念。

现代文阅读（二）《春天的节奏》

12 分 · 康健 · 考点：写作顺序 / 结尾作用 / 朗读设计 / 拓展阅读

①北京的春天，总是从容不迫带着自己的节奏，农历二月、三月、四月，一步步走来，顾盼生辉。

②早春二月时，我路过公园的土坡旁，发现有亮眼的小花在悄然绽放，一点、几点，一小片、一大片……就像是一张张调皮孩子的灿烂笑脸，天真无邪又肆无忌惮地惹逗你，似乎都能听见花丛中传出的咯咯的笑声。

③看远处，朝阳的柳树梢上，已有一抹亮色的鹅黄点染，像是高悬的米黄酒旗，又像是万千流苏迎风摆动，提醒人们春意已闹上枝头。北方的柳树多高大伟岸，看似粗粝豪放一些，却也呈现出潇洒妩媚的面相。柳色鹅黄新绿，也是春来的播报。

④时令进入三月，春意开始浩荡。草色一天比一天绿，也一天比一天深。园中的花木由爆蕾而发华，而生新叶，而成花海、成绿阵。所有这些，都不用等上多少天，变化好像就是瞬息之间的事，稍不留神便会错过。

⑤才几天不见，草地新绿已是无边蔓延，明亮晃人眼。每一根小草都挺直了腰肢，像花枝招展的小姑娘，通体新鲜闪亮，是努力生长的样子。而抬眼远望，几片小树林集体着了春衫。最惹眼的是春阳照耀之下，一树树的新叶也一天天长大不少，发出油亮而柔和的光泽。而各种花儿这时候已次第盛开，红的桃花，白的梨花、杏花、海棠花，还有各种粉的不知名字的什么花，一树树，一丛丛，高高低低盛开，各自乐此不疲。园中湖泊和池塘都是水清见底，倒映着周围的绿树杂花，居然还有偶尔几声零星的虫鸣，呈现出一种幽远静谧之美。林间、花丛，河边、路上，有各色各样好看的小鸟落下、飞起、掠过，三五成群，啾啾啁啁，叽叽喳喳，七嘴八舌很热烈的样子。

⑥四月春深，已至暮春。绿色的规模和程度都大大地推进，到了一个前所未有的境界，所有的空间乃至所有的空白都被绿色充满。满坑满谷的绿意足够盛大，在地上膨胀溢出，还想往天上去。于是，看到那些遍地铺陈、漫无际涯的绿意真的就飞上天了。一树一树成排连片，腿脚扎进绿色的海洋，挺拔的腰身向空中延伸，披挂茂盛的绿叶连天蔽日。暮春是春之盛。此时的春天，是青春勃发，是风华正茂，热情迸发，活力彰显。

⑦春意最浓，花事也最盛，大地就是一座大花园。这个时候，有花开，也有花落，一茬接着一茬。这边厢，花开正欢；那边厢，落英缤纷。花有花期，不过，大可不必伤春，在当下尚是脉脉温情，在前方更有炙人的热情，新陈代谢更加频繁，生命也会加速成长。

⑧也该说说春雨了。春雨贵如油，是对春雨的夸赞，也透露出人们对春雨的期盼之情。悠闲的人在春燥时盼春雨，是为了让春雨滋润心田，给生活添加诗意；四季忙碌的农人在春耕时也盼春雨，是为了让春雨滋润禾苗，给一年好收成打下基础。"好雨知时节，当春乃发生"，经过雨水洗染的大地，花木扶疏，草色新绿，水汽氤氲于天地之间，不外是浓浓的春天的气息。

⑨人们在春天之初做出各种计划，播种希望的种子，心心念念全是向着前方和未来。一年又一年，人们盼春、迎春、惜春，是因为春天总是激励着一整年的奋斗与创造。

半命题记叙文 ·「触动心弦的_____」

一朵白莲，点燃了冰心对母爱的诗情；一滴水，触发了海伦·凯勒对生命的热爱；一片菊花寄托了史铁生对母亲的怀念……物虽微，事虽小，真意在其中。什么触动了你？为什么触动了你？你从中懂得了些什么？

请以"触动心弦的_____"为题目，写一篇记叙文。

要求：①在横线上填写合适的内容，把题目补充完整，然后作文。②表达意图明确，内容具体充实。③600 字左右。④文中请回避与你有关的人名、校名、地名。

审题三个关键点

①"触动心弦"是心灵被深深打动。不是一般的"看到""经历"，而是引发情感共鸣、带来认知改变的瞬间或事物。补题的对象必须能承载这份"触动"。

②重点不在"是什么触动了你"，而在"为什么触动 + 你懂得了什么"。题目要求写清三层：触动之物 → 触动之因 → 触动之悟。只写触动的过程而不写感悟，是流水账。

③补题要具体可感。补得太大会空（"触动心弦的爱"），补得太小会窄（"触动心弦的一句话"要有足够的故事支撑）。好的补题 = 具体意象 + 有故事 + 能生发感悟。

三类补题方向　人：触动心弦的背影／触动心弦的那个眼神；物与景：触动心弦的那片落叶／触动心弦的一树花开／触动心弦的一盏灯；抽象：触动心弦的一句话／触动心弦的那个瞬间。

避坑　①不要写成"令我感动的事"但没有"触动心弦"的深层感悟；②不要编造重大事件（车祸、重病）；③不出现真实人名、校名、地名。

结构三镜头式（最适合 600 字）

开头（约 80 字）　场景切入：什么时间、什么地点、一个具体的动作。用一句话点出"触动"的触发点。

主体（约 440 字）　三个镜头层层推进：

　镜头一「见」——环境 + 特写。触动你的事物（人/物/景）是什么样子？哪个细节最先击中你？

　镜头二「触」——停留 + 心理。你停下脚步/愣住的瞬间，想到了什么？（要有一处细节特写与一处心理转折，是全文最用力的地方）

　镜头三「悟」——改变 + 升华。你因此明白了什么？做了什么不一样的事？（落到"懂得了什么"）

结尾（约 80 字）　回扣"触动心弦"，以小见大，留一句有余味的话。不要写"这件事让我明白了一个道理"。

范文触动心弦的一树花开（约 620 字）

初三第一次模考成绩出来那天，我攥着成绩单，一个人绕到教学楼后面的小路上。

数学那栏的数字像一根刺，扎得我眼眶发酸。我不敢回教室，怕看见别人的眼神，更怕看见母亲来接我时那张强装轻松的脸。

小路尽头有一棵老石榴树。不知什么时候，它已经开花了。

红红的石榴花，一树树，一簇簇，一团团，缀满在斑驳的老枝上，像一簇簇跳动的火苗。树干上有碗口粗，皮裂着，斑斑驳驳，一看就是经了许多年的风雨。可花开得那样满、那样盛，仿佛把所有的力气都用在了这一刻。风吹过来，几瓣花落下来，铺了一地红色，可树上还是满满的，看不出少了什么。

我站了很久。想起外婆院子里也有过这样一棵石榴树，母亲小时候就围着它转。那棵树也是这样，每年五月，不声不响地开，不管有没有人看，不管这一年是丰收还是歉收。

它不知道自己长在哪里，不知道有没有人为它喝彩，可它还是开了，开得那么认真、那么热烈。

我忽然觉得自己有点可笑。一次考试失利，就把自己缩进了壳里；而一棵树，站在那么不起眼的角落，却把花开成了自己的节日。

那天回家，我把成绩单压在台灯下，拿出错题本，一道一道地重做。窗外的天暗下来的时候，我好像又看见了那树石榴花在风里燃着的样子。

后来每次路过那条小路，我都会看看那棵石榴树。花开一季，花落一季，可它从不辜负自己的春天。而我也要学会，在自己的位置上，认真地、热烈地，把花开完。

点评　①补题具体可感，"一树花开"既是物象也是象征；②结构完整：迷惘（成绩）→ 遇见（石榴花开）→ 触动（"把花开成了自己的节日"）→ 改变（重做错题）→ 升华（"不辜负自己的春天"）；③细节扎实："一树树，一簇簇，一团团""皮裂着，斑斑驳驳""几瓣花落下来，铺了一地红色"，全是特写，没有空喊"坚强"；④首尾呼应，结尾不说教、有余味；⑤字数约 620 字，符合"600 字左右"。
