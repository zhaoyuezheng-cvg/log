概括题（概括人物特点 / 事件）
方法 + 示例 ▼
1.1
概括人物行为 / 特点
《中国地图》
从原文找到具体描写 → 提炼为四字/短语概括 → 分点罗列（①②③④）

示例：概括爷爷对地图的喜爱

①"退休后每天对着地图默默地看，有时还自言自语" → 退休后还经常查看地图
②"家里有人的时候，总要给人家讲述地图上地名背后的故事" → 喜欢��述地图上地名背后的故事
③"爷爷两眼放光，戴着老花镜，趴在地图上瞅起来" → 对新地图兴趣浓厚
④"伶仃洋上咋有一座桥？新建的" → 敏锐发现新地图中的细微变化
每条都是"原文细节 → 提炼概括"，不要照抄原文，要压缩成短语
1.2
概括人物成长经历
《方志敏传》
按段落顺序定位关键句 → 提取动作行为 → 用动词短语概括

示例：概括"我"怀念父亲的具体表现

①第⑥段"这句话深深地触动了我。从那以后，我发愤用功读书" → 发愤用功读书，��习文化
②第⑨段"从《可爱的中国》起，我才开始真正认识父亲" → 通过读父亲写的书去认识、了解父亲
③第⑩段"母亲��世了，我就接过母亲的担子，延续着与父亲革命战友的血肉联系" → 延续与革命战友、家乡人民的血肉联系
④第⑪段"1986年退休后，我开始全身心投入寻访父亲革命足迹的事业" → 寻访父亲革命足迹，为父亲写作《方志敏全传》
按时间/段落顺序分点，每点对应一个段落的关键动作

词语赏析（能否替换 / 删除）
方法 + 示例 ▼
2.1
"能否替换/互换"题
《中国地图》
首先回答"能 / 不能" → 分别解释两个词的本义和侧重 → 结合原文分析替换后的效果变化

示例："故事"与"事故"能否互换？

第一步（表态）：能。

第二步（释词）：
"故事"指旧事、旧业、先例、典故等，侧重传奇色彩；
"事故"（多指生产、工作中）发生的意外损失或祸患，侧重意外。

第三步（结合原文）：
原文写爷爷在河南嵩山被三只饿狼盯上、在陕西榆林遇飞沙走石保护仪器等情节，突出了爷爷当年测绘工作的艰辛和危险。

第四步（分析互换效果）：
"事故"侧重意外，"故事"侧重传奇色彩，互换后突出了爷爷对事业的热爱，对付出的无悔。
必答"能/不能"开头，再分两词解释，最后落到"表达效果/情感"的变化

标题含义 / 词语多义赏析
方法 + 示例 ▼
3.1
标题的多重含义
《中国地图》
由表及里，逐层挖掘：①字面义（实物）→ ②象征义（人物内心）→ ③时代义（折射变化）→ ④情感义（热爱/骄傲）

示例：分析"中国地图"的含义

���字面义（实物）：
"爷爷曾是地图绘制工程师，绘了一辈子地图" → 指文中的中国地图实物。

②内心义（人物）：
"总要给人家讲述地图上地名背后的故事" → 指装在爷爷心中的中国地图。

③时代义（变化）：
"伶仃洋上咋有一座桥？""丹江口水库咋新增一条支流？" → 新旧地图的变化折射出祖国建设取得了伟大成就。

④情感义（主旨）：
"中国地图"承载着地图测绘人对中国地图测绘事业的热爱与追求；蕴含了对祖国发展的骄傲与自豪之情。
从"物→人→时代→情"四个层次递进，每层都要结合原文细节
3.2
修辞手法赏析
《中国地图》
找出修辞 → 分析作用（形象生动 + 表现内容 + 表达情感）
"再活五百年""在福窝里还没扑腾够"
运用夸张、比喻的修辞方法，形象生动，充满感情色彩，表现了爷爷对时代、对事业、对生活的热爱。

句段作用（开头段 / 中间段）
方法 + 示例 ▼
4.1
开头段作用
《方志敏传》
结构作用（总领/悬念/铺垫） + 内容作用（点题） + 情感作用（奠定基调）
第①段"我一生只见过父亲方志敏两次"
①总领全文，设置悬念，引起读者的阅读兴趣；
②"但是够我怀念一辈子的了"饱含对父亲的怀念之情，为全文奠定了"怀念父亲"的感情基调。
4.2
中间段作用（承上启下）
《袁隆平》
分"结构 + 内容"两方面答：结构看承上启下，内容看突出什么精神
结构方面：
前文讲袁隆平决定研究杂交水稻及研究过程，后文侧重他在科研一线的坚持。此段处于中间位置，起到承上启下的作用——承接上文研究杂交水稻的背景，引出下文他持续为科研努力及对他人的影响。

内容方面：
体现袁隆平经历的苦难，以及他为改变人们生活所付出努力的意义，突出他的奉献精神。
中间段必答"承上启下"，并具体说明承了什么、启了什么

人物形象分析
方法 + 示例 ▼
5.1
结合事件概括品质
《方志敏传》
找原文事件 → 提炼四字品质 → 一事一品质，分点作答
①"父亲一生忠贞不屈，到了最后牺牲自己的一切，都是为了'救国'" → 忠贞爱国
②"在狱中用生命写下了感人肺腑的《可爱的中国》《清贫》等名篇" → 坚定的信仰和信念
③"为战火岁月中出生的5个孩子，分别取名为松、柏、竹、梅、兰" → 高洁的品格
5.2
人物形象跨文比对
《鲁迅》
选定最符合的材料 → 结合已学课文（《阿长》《藤野先生》）印证 → 多角度论证
示例一（选材料二·认真随和）：
在《阿长与＜山海经＞》中，面对淳朴善良的长妈妈，鲁迅虽偶尔憎恶，但因她讲长毛故事和买来山海经而变得随和近人；在《藤野先生》中，面对认真负责的老师时，鲁迅性情随和，认真对待学习。

示例二（选材料三·爱国者）：
爱国是鲁迅一生的主旋律。《藤野先生》中中国人被认为是"低能儿"，鲁迅决定弃医从文，从精神上唤醒国人；在北大校徽设计中，蕴含着对北大学子的希望。
跨文比对必须引用学过的课文作论据，不能只说空话
5.3
"平凡"与"不平凡"辩证分析
《袁隆平》
先解释词语本义 → 结合原文分别举证"平凡"和"不平凡" → 总结升华
"平平无奇"：生活中袁隆平对吃穿不讲究，衣服打折时10元一件的衬衫能买十几件，和普通人一样，生活物质方面平凡普通。

"不平凡"：他是杂交水稻研究领域开创者和带头人，面对科研困难知难而进，经十几年努力攻破技术难关，让粮食增产解决温饱问题；鲐背之年仍活跃科研一线，一生为让所有人远离饥饿而奋斗，成就和奉献极其伟大。

神态判断 / 语言描写赏析
方法 + 示例 ▼
6.1
根据语句判断人物神态
《鲁迅》
看涉及对象（敌/友） → 分析修辞/用词 → 推断说话人态度 → 给出神态词
A 句（对象是政见不同的伪君子）：
神态：冷静沉稳、淡然坚毅、斗志昂扬。
理由：鲁迅把自己比作具有战斗性的雄鸡，形象写出与敌人斗争时的思维冷静，毫不畏惧，表达了与恶势力抗争到底的决心。

B 句（对象是思想要求进步的青年）：
神态：无可奈何、皱眉叹气、垂头丧气。
理由："胡乱"说明青年写信只管速度忽略质量，是做事敷衍。鲁迅否定青年们敷衍的态度，但青年写信是希望得到前辈指点，所以神态应是无可奈何——既不满又关心青年进步。
神态判断关键看"说话对象"是敌是友，决定态度是"斗争"还是"关爱"
6.2
语言描写的作用
《袁隆平》
指出描写方法 + 引述内容 + 分析体现的品质 + 表达的情感
运用语言描写，通过袁隆平对学生的期许和叮嘱，体现他淡泊名利、重视理想追求的高尚品质。
语言描写答题：描写方法 + 内容 + 人物品质，三步缺一不可
6.3
读后感 / 续写表达
《方志敏传》
紧扣文章主旨 + 联系现实成就 + 抒发情感（致敬式表达）
示例（给方志敏爷爷的回话）：
方志敏爷爷，如您所愿，我们的祖国非常可爱！您看，今日之中国，飞船直上云霄，航母劈波斩浪，大桥横跨天堑，高铁穿行不息。我们的国家一天比一天富强，我们的生活一天比一天幸福！
用排比句式列举国家成就，情感真挚，呼应原文"可爱的中国"主题
