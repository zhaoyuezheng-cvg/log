一、项目整体概述 1.1 项目背景与核心痛点 用户孩子为初一学生，整体成绩良好，但存在学科基础短板：语文基础字词、文学常识掌握不扎实；英语单词、短语、句型高频出错；数、政史地生（小四门）错题无系统化整理、复盘效率低。同时家长已购置云服务器，可自主部署项目，无需依赖第三方平台，数据安全可控。 当前传统错题本、笔记工具痛点：手动录入繁琐、无法智能纠错、无知识点拓展、无法针对性沉淀个人易错题库、缺乏适配初一同步教材的专属学习辅助能力。 1.2 项目定位 一款初中生专属AI全科易错点&amp;错题管理APP，聚焦初一同步学习，主打拍照录入、语音录入、AI智能纠错/解析/整理，分学科沉淀个人易错知识库，搭配家长后台管理功能，轻量化、无娱乐干扰，纯学习工具属性，适配初中生日常查漏补缺。 1.3 部署基础 依托用户自有云服务器部署，搭载移动端APP（手机端）+ Web后台管理系统，数据本地云端存储，独立管控，安全稳定。 二、整体架构设计（适配私有云服务器） 2.1 系统整体架构 采用「前端APP + 后端服务 + AI能力接口 + 云服务器数据库 + 管理后台」五层架构，轻量化部署，适配个人云服务器配置，不占用过高资源。 移动端前端：安卓APP（适配安卓手机、安卓平板），面向学生使用，承载所有录入、查询、学习、复盘功能 后端服务：部署于用户自有云服务器，负责数据接收、存储、逻辑处理、接口调度 AI能力层：对接通用AI接口，实现OCR拍照识别、语音识别、错题解析、知识点纠错、内容拓展 数据库层：云服务器自建数据库，存储学生易错知识点、错题、学习记录、用户数据 后台管理端：Web网页端，家长可登录，查看学习数据、管理题库、查看薄弱点 2.2 核心核心优势 私有化部署：自有云服务器，孩子学习数据不泄露，完全自主可控 学科精准适配：完全贴合初一语数英、小四门考点，摒弃无用功能 多方式录入：拍照、语音、手动三种录入方式，解决录入繁琐问题 AI智能赋能：纠错、解析、拓展、整理一体化，精准弥补基础短板 专属知识库：沉淀个人易错题库，针对性复盘，精准提分 三、分学科详细功能设计（核心业务功能） 严格按照家长需求，分语文、英语、数学、小四门四大模块定制功能，完全匹配初一学习短板。 3.1 语文模块（针对性解决基础薄弱问题） 核心定位：专攻易错字词读音、易混字词短语、文学常识、古文基础四大薄弱点 3.1.1 录入方式 拍照录入：拍摄试卷、课本、笔记中的易错字词、古文、文学知识点，AI自动识别文字，去除杂质、筛选有效知识点 手动录入：自主输入记错的字音、字形、短语、文学常识、古文实词虚词 3.1.2 AI核心能力 AI智能矫正：自动纠正错误读音、错字、别字、误用短语，标注错误原因（如：形近字混淆、多音字误读、搭配不当） AI知识点拓展：针对录入知识点，自动拓展同类易错点、近义词、反义词、固定搭配、教材同步考点 古文专项解析：针对录入的古文字词、句式、翻译，AI补充注释、古今异义、词类活用、重点翻译、课文出处 文学常识整理：零散录入的文学常识，AI自动分类整理（作者、朝代、作品、文体、主旨） 3.1.3 数据沉淀功能 自动分类归档：字音易错库、字形易错库、短语误用库、文学常识库、古文基础库 支持错题/易错点复盘、随机抽查、错题重做、重点标记 3.2 英语模块（解决单词、句型高频出错问题） 核心定位：专攻易错单词、短语、易错句型、英语错题，支持多维度智能录入与拓展 3.2.1 录入方式（三大录入模式） 拍照录入：拍摄英语错题、单词默写错题、短语造句错题，AI精准识别英文内容 语音识别录入：口语朗读易错单词、句型，系统语音转文字，自动记录录入内容，适配口语纠错、记忆场景 手动录入：自主记录拼写错误、搭配错误、句型误用知识点 3.2.2 AI核心能力 AI纠错矫正：纠正单词拼写错误、短语搭配错误、语法句型错误，标注错误语法点 AI智能拓展：自动拓展单词词性、复数、过去式、固定搭配、同义替换、初一必考句型、同类易错语法 错题解析：针对英语单选题、完形、填空等错题，AI给出详细解析、考点、易错提醒 3.2.3 数据沉淀功能 自动归档：易错单词库、易错短语库、易错句型库、英语错题集，支持单词听写、句型默写、错题复盘 ...

Git常见命令

一、初始化 & 克隆（第一次用） # 1. 本地新建 git 仓库 git init # 2. 克隆远程仓库到本地（最常用） git clone https://github.com/xxx/xxx.git # 3. 查看远程仓库地址 git remote -v # 4. 添加远程仓库（本地关联远程） git remote add origin 仓库地址 二、日常提交（改代码→上传本地） # 1. 查看状态（哪些文件改了、新增了） git status # 2. 把所有修改加入暂存区（最常用） git add . # 3. 提交到本地仓库，带说明（必须写清楚） git commit -m "feat: 新增文章/修复bug" # 4. 快捷：已跟踪文件直接提交（跳过 add） git commit -am "fix: 修复首页样式" 三、同步远程（本地 ↔ GitHub） # 1. 拉取远程最新代码（避免冲突，必做） git pull origin main # 2. 推送本地到远程（第一次要 -u） git push -u origin main # 之后直接 git push # 3. 强制推送（覆盖远程，谨慎！） git push --force 四、分支管理（多人协作/多版本） # 查看本地分支 git branch # 查看本地+远程所有分支 git branch -a # 创建分支 git branch dev # 切换分支（旧版） git checkout dev # 创建并切换（推荐） git checkout -b dev # 新版更直观 git switch -c dev # 合并 dev 到 main git checkout main git merge dev # 删除本地分支 git branch -d dev # 删除远程分支 git push origin --delete dev 五、查看日志 & 对比 # 完整提交日志 git log # 简洁版（一行一个，推荐） git log --oneline # 最近 n 条 git log --oneline -5 # 看具体文件改动 git diff 文件名 # 看暂存区和仓库差异 git diff --staged 六、撤销 & 回退（改错了怎么办） # 1. 撤销工作区修改（未 add） git restore 文件名 # 2. 撤销暂存（add 了但没 commit） git restore --staged 文件名 # 3. 撤销最后一次提交（保留修改） git reset --soft HEAD~1 # 4. 彻底回退（危险！丢代码） git reset --hard HEAD~1 # 5. 安全撤销某次提交（生成新提交，不改历史） git revert 提交id 七、标签（版本发布用） # 打标签 git tag v1.0 # 推送标签到远程 git push origin v1.0 # 删除本地标签 git tag -d v1.0 # 删除远程标签 git push origin --delete v1.0 八、日常工作流（你用 Hugo/GitHub Pages） # 写新文章后 hugo --minify git add . git commit -m "新增文章：xxx" git pull origin main # 先拉，避免冲突 git push

一份精简、实用的 Hugo 命令速查。 一、项目创建 & 初始化 # 1. 新建站点（在当前目录下创建 myblog 文件夹） hugo new site myblog # 2. 进入项目目录 cd myblog # 3. 初始化主题模块（新版 Hugo 推荐） hugo mod init github.com/你的用户名/你的仓库名 二、写文章（最常用） # 新建一篇文章（自动生成 frontmatter，draft=true 草稿） hugo new posts/第一篇文章.md # 新建页面（如 about、contact） hugo new about.md 三、本地预览（开发） # 启动本地服务器，默认 http://localhost:1313，热更新 hugo server # 🔥 常用：预览包含草稿（draft=true）的文章 hugo server -D # 自定义端口（如 8080） hugo server --port 8080 # 绑定到所有网卡（手机/局域网访问） hugo server --bind 0.0.0.0 四、构建发布（生产） # 构建静态文件到 public/（默认，不含草稿） hugo # 🔥 生产环境压缩（HTML/CSS/JS 最小化，推荐） hugo --minify # 构建并包含草稿（临时用） hugo -D # 指定输出目录（默认 public） hugo -d ./dist 五、日常工作流（你用 GitHub Pages） # 1. 写新文章 hugo new posts/xxx.md # 2. 本地预览 hugo server -D # 3. 确认后，把草稿改为正式：把 md 文件里 draft = false # 4. 构建生产文件 hugo --minify # 5. 提交到 Git 并推送 git add . git commit -m "发表新文章" git push 六、模块 & 主题管理（常用） # 拉取主题/模块更新 hugo mod get -u # 清理模块缓存（解决依赖报错） hugo mod clean --all # 整理 go.mod（删除无用依赖） hugo mod tidy 七、排错 & 信息 # 查看版本 hugo version # 查看帮助 hugo help hugo server --help # 列出所有草稿 hugo list drafts # 清空 public 再构建（避免旧文件残留） rm -rf public && hugo --minify 八、常用参数速查表 -D / --buildDrafts：包含草稿 --minify：压缩代码（生产必加） --port 端口：自定义端口 -v：详细日志（排错用）
